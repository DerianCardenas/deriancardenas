memory SICROP — Agentes de IA para Compras (2026)

Integración de agentes de IA en un sistema de compras existente. Desarrollé tres flujos complementarios: solicitudes por conversación, asistencia para negociar con proveedores y monitoreo programado de situaciones que requieren revisión humana.

Mi aportación

  • Solicitudes por chat con validación de presupuesto
  • Recomendaciones a partir del historial de compras
  • Alertas configurables sobre la operación
Mi aportación y detalles técnicos

code Aportación Personal (Agentes de IA Desarrollados):
• Agente Conversacional: Recibe pedidos por chat (ej. "quiero tres laptops para mañana"), propone opciones del catálogo, comprueba presupuesto, muestra vista previa, permite cambios por texto o interfaz y envía la solicitud al superior.
• Agente de Negociación: Examina el historial de compras previas, productos, precios y vendedores para mostrar tendencias de mercado y sugerir alternativas de compra o estrategias de negociación.
• Agente Monitor / Cron Configurable: Supervisa el sistema enviando alertas sobre solicitudes atascadas, presupuestos cerca del límite y compras acumuladas que superan umbrales en un periodo definido.

settings Decisiones Técnicas: Integración de Anthropic Claude API con flujos en Vue 3, .NET y PostgreSQL.

warning Nota de Auditoría: Las alertas generadas por el monitor identifican posibles anomalías operativas y desvíos para revisión humana, no fraudes comprobados.

El reto y cómo lo abordé

Una petición como «quiero tres laptops para mañana» se convierte en una propuesta basada en el catálogo. El usuario puede revisar y modificar la solicitud antes de enviarla a su superior. El asistente de negociación consulta compras previas, mientras que el monitor identifica solicitudes atascadas y umbrales presupuestales para su revisión.

Vue 3 .NET PostgreSQL Anthropic Claude API Agentes Conversacionales Monitores Cron
